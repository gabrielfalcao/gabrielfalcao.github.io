## Object Center & Symmetry

<iframe title="vimeo-player" src="https://player.vimeo.com/video/1044429075?h=1e68b395d6" width="640" height="360" frameborder="0" referrerpolicy="strict-origin-when-cross-origin" allow="autoplay; fullscreen; picture-in-picture; clipboard-write; encrypted-media; web-share"   allowfullscreen></iframe>

Blender Add-On with 2 specific features:

- Clear object location above surface (`Ctrl+T`): Similar to `Clear Location`
  (`Alt+G`) but places the object above the Z axis and at the X and Y
  axis based on the objects X anx Y dimensions, that is, `0 + (X / 2)` and `0 + (Y / 2)`.

- Distribute Objects Along Axis (`Command+Shift+D`)

- Distribute Objects Along the X Axis (`Ctrl+Alt+X`)

- Distribute Objects Along the Y Axis (`Ctrl+Alt+Y`)

- Distribute Objects Along the Z Axis (`Ctrl+Alt+Z`)

- Set Origin to Geometry and Reset 3D Cursor (`Alt+O`)

- Apply Active Material to Selected Objects (`Command+Shift+M`)

- Cleanup Unused Materials (`Shift+Alt+M`)
